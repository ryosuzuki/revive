# Public synthetic media

`agent-hands-synthetic-preview.jpg` contains four frames of the actual Unity gesture runtime rendering an explicitly authored box-and-hands fixture. No camera recording, person, private room, generated response or physical Quest test is shown.

The matching eight-second MP4 is attached to the paper-versioned release. Reproduce with Unity's `RenderSynthetic.Run`, setting `REVIVE_SYNTHETIC_OUTPUT` to an empty output directory; then run `scripts/package_synthetic.py FRAMES OUTPUT`. Four two-second phases show point, present, measure and rotate. Each frame is labeled synthetic/no-gaze.
